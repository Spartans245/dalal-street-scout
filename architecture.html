EVAL_WORKER.PY  EOD STEP 6
Scope: Signal-tier stocks — top 3 per phase (post_cross, breakout, pullback, coiling, trending) sorted by F+T desc → upsidePct desc → mcap desc
All-tab: top-3 by F+T+S — adds any not already selected
Baseline: all remaining 2526 stocks tracked but tier=baseline (not shown in UI)
Per stock: ticker, stage, tier, day0, score, price_d0, prices{}, nifty_d0, nifty_prices{}, outcome, outcome_ret/day/date, stage_history[], upsidePct_d0
writes → data/signals_log.json
ANALYTICS_WORKER.PY  EOD STEP 7
Input: signals_log.json (reads only, never writes)
Checkpoints: D7, D14, D21, D30, D45, D60
Per stage per checkpoint: stock median/mean return, NIFTY median/mean, alpha median, n
Distribution: wins (≥+15%), losses (≤−9%), best, worst at each checkpoint
Lifecycle: sequence adherence, path_map (all unique paths + win rate), days_to_outcome by stage
writes → data/evals/analytics.json
LIFECYCLE_WORKER.PY  EOD STEP 8
Scope: ALL 2526 NSE stocks — independent of eval_worker
D0 Snapshot (36 fields): RSI, ADX, EMA signals, VPB, F/T/score, PE, D/E, ROE, mcap, sector, 52W/38W high/low, upsidePct, sr_resistance[], sr_support[], vol_ratio, close_pos, daily_vol_cr
Daily tracking: prices{}, phase_log[] (phase changes + day_n), path (numbered 1–6), outcome (OPEN/WIN/LOSS/EXPIRED)
Targets: WIN +15% · LOSS −9% · EXPIRED day 60 → D0 resets on outcome
resolved_cycles[]: full history of past cycles archived per stock
writes → data/lifecycle_log.json (~2526 stocks)
